# Comparaciones y Ciclos en Lenguaje Ensamblador Intel x86

## Ejercicios

1. Dados dos numeros 'n1' y 'n2', hacer una funcion que imprima un mensaje informando el resultado de la comparacion.

2. Dado un numero 'n1', hacer una funcion que calcule $n!$.

3. Dado un vector de caracteres, hacer una funcion que le pida un caracter al usuario. Si está dicho caracter, imprime el índice donde se encuenta. En caso contrario, imprime -1.
